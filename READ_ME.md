Команде нужен разработать универсальный движок, позволяющий описывать процесс обработки текста декларативно.
Задача: Создать модульную систему, которая принимает "сырой" текст и с помощью настраиваемой цепочки преобразований 
превращает его в структурированные, чистые данные, готовые для анализа.
1. Режим исполнения конвейера (Pipeline Runner)
   Система должна:
   Читать конфигурационный файл в формате YAML
   Последовательно применять указанные шаги обработки
   Передавать результат каждого шага на вход следующему
   Сохранять финальный результат в указанном формате
2. Режим анализа и предложения конфигурации (Config Proposer)
   Система должна уметь:
   Принимать два файла:
   input_sample.txt — образец необработанных данных
   target_sample.txt — образец желаемого результата
   Анализировать различия между ними
   Генерировать предположительный конфигурационный файл, который может преобразовать исходные данные в целевые
   Критерий успеха: Сгенерированный конфиг при запуске в первом режиме должен производить результат, максимально близкий к целевому образцу.
